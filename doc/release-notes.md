# Make a Ten - Release Notes

## 1.1 (in progress)

### New Features
* Improved artwork
   * Paper ones are now easier to decompose
   * Screen and game level icons updated
* Added sound effects for numbers
   * Pick up and drop
   * Composition and decomposition
   * Repelling
* Improved layout
* Support Dynamic Layout
   * Pan and zoom
   * Translation support
* TypeScript implementation

### Bug Fixes
* General bug fixes that made the sim crash are fixed
